# Nico Alexander Bauer

Persönliche Bewerbungswebsite: https://nico-alexander-bauer.de/

Statische HTML-, CSS- und JavaScript-Dateien. Keine Build-Abhängigkeiten, externen Schriftarten oder Analysewerkzeuge.

## Bearbeiten

- `index.html`: berufliches Profil, Erfahrung, Projekte und Kontakt
- `styles.css`: Gestaltung für Desktop, Mobilgeräte und A4-Druck
- `script.js`: Navigation, Drucken und E-Mail-Kopierfunktion
- `kontakt-datenschutz.html`: Impressum und Datenschutzhinweise
- `CNAME`: eigene Domain für GitHub Pages

## Veröffentlichung

GitHub Pages verwendet Branch `main`, Ordner `/ (root)`. Änderungen auf `main` werden automatisch veröffentlicht. Die Domain wird bei IONOS verwaltet; E-Mail-DNS-Einträge bleiben bestehen.

Die Seite nennt keinen abgeschlossenen Studiengrad und keine unbestätigten Leistungskennzahlen. Bewerbungsunterlagen werden auf Anfrage bereitgestellt.
